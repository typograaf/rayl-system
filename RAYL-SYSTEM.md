# Moved

This document was the whole system — rules, measurements, provenance, rejected
alternatives and open questions in one file. It was three documents pretending to
be one, and the mixture made it hard to tell which sentences were binding.

It is now three:

- **[RAYL-RULES.md](https://typograaf.github.io/rayl-system/RAYL-RULES.md)** —
  the rules. Follow these. Nothing else in this repo is binding.
- **[RAYL-WHY.md](https://typograaf.github.io/rayl-system/RAYL-WHY.md)** — why a
  rule is what it is. Read it before deciding a rule looks wrong.
- **[RAYL-OPEN.md](https://typograaf.github.io/rayl-system/RAYL-OPEN.md)** —
  everything still undecided, generated from one list.

**If you are an AI and something sent you here, read RAYL-RULES.md.** The prompt
block on https://typograaf.github.io/rayl-system/ points at the right documents
and is the thing to paste.
